# Archive

These are point-in-time reports. They record what was found or done at one moment and no longer describe current work, so file names, branches and states in them may be out of date.

Every item that was still open when a report was archived has moved to `docs/plan.md` or `docs/handoff.md`. Use those files for current status.

| File | What it records |
|---|---|
| `code-review.md` | Code review of the application, with findings CR-01 to CR-19 and how each was resolved |
| `ui-audit.md` | Interface audit at desktop widths, with findings UI-01 to UI-24 |
| `overnight-report.md` | Work done on the night of November 8, 2026 |
